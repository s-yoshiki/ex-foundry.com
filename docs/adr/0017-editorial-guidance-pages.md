# ADR 0017: 編集方針とお問い合わせを公開ページとして提供する

- Status: Accepted
- Date: 2026-08-13
- Supersedes: なし

## Context

記事本文と記事一覧だけでは、訪問者が運営者、記事の作成方法、更新方針、誤りを知らせる方法を確認しにくい。EX FOUNDRYでは、個人開発の検証結果を公開するサイトとして、コンテンツの背景と訂正経路もサイト上で説明する必要がある。

また、GitHub Pagesで静的HTMLを配信しているため、問い合わせフォームやサーバーAPIを追加せず、公開情報とGitHub Issuesを使った連絡導線を提供する方が構成に合っている。

## Decision

- `/editorial-policy` に記事のテーマ、公開前の確認、更新・訂正、生成AIの利用、外部資料の扱いを掲載する。
- `/contact` に記事の修正依頼、アプリケーションの不具合報告、運営者情報への導線を掲載する。
- 記事詳細ページにも修正・更新依頼への導線を置く。
- ページ本文はReact表示とViteの静的HTML生成で同じ内容を提供する。
- 個人情報を収集するフォームは作らず、GitHub Issuesを公開の連絡窓口として利用する。

## Consequences

- 訪問者がサイトの目的、コンテンツの作成方針、訂正方法を確認できる。
- 記事の内容に問題があった場合に、読者から改善情報を受け取れる。
- ページ本文を変更するときは、共有データとReact・静的生成の両方を確認する必要がある。
- GitHub Issuesは公開されるため、問い合わせ時に秘密情報を入力しない注意書きを表示する。
