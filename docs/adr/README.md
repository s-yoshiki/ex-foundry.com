# Architecture Decision Records

このディレクトリは、`ex-foundry.com` に関する技術的な判断と決定事項を記録する場所です。

- ファイル名は `NNNN-kebab-case.md` とし、番号は連番にする。
- 状態は `Proposed`、`Accepted`、`Superseded`、`Deprecated` のいずれかで記録する。
- 新しい判断は実装前に追加し、既存の判断を変更するときは元の記録を上書きせず新しいADRを追加する。
- 既存の `docs/decisions/` は過去の決定記録として保持する。新規記録はこのディレクトリに追加する。
